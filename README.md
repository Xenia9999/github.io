# github.io

GitHub Pages site for the PDF to GPX Converter project.

## Main Repository
The main application code is in the [PdfToGpxConverter-4](https://github.com/Xenia9999/PdfToGpxConverter-4) repository.

## This Repository
This repository hosts the static GitHub Pages site at https://xenia9999.github.io/

The site provides information and links to the main PdfToGpxConverter-4 application.

## Deployment
The site is automatically deployed via GitHub Actions when changes are pushed to the main branch.
